# Installing Phelix

Phelix has no packages or pre-built binaries.
[Build it from source](./building-from-source.md).

To take full advantage of Phelix, install the language servers for your
preferred programming languages. See the Helix
[wiki](https://github.com/helix-editor/helix/wiki/Language-Server-Configurations)
for instructions.

To see the runtime directories that `phx` searches, run `phx --health`. If necessary, you can override the default runtime location by setting the `PHELIX_RUNTIME` environment variable.
